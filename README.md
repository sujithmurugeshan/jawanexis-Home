# HCL GUVI Inspired Landing Page

This project contains a React + Tailwind landing page recreated from the supplied screen recordings of guvi.in.

## Open the page

Open `index.html` directly in a browser.

The page now follows the visible video flow:

- Sticky GUVI/HCL-style header
- Hover dropdown menus
- Summer offer hero banner
- Accreditation and partnership cards
- Live Classes + Placement Guidance section
- Large program cards with image-style thumbnails
- Carousel controls and Explore All Programs button
- Path chooser banner
- Learner story cards
- Student workplace logo grid and stats
- Course carousel section
- Practice platform section
- Final CTA and footer
- Course listing preview with language filters, sort, explore, and search

The page uses:

- React from CDN
- Tailwind CSS from CDN
- DM Sans font from Google Fonts
- One original generated summer offer banner at `src/assets/offer-hero.png`
- Four original generated course-card thumbnails in `src/assets/course-*.png`

## Note

This matches the recording's layout and visual rhythm closely, but it does not reuse GUVI's protected images, exact logo files, or exact page assets. The banner and card visuals are original recreations.
